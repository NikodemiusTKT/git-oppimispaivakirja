# Git-versionhallinnan oppimispäiväkirja

**Tekijä:** Teemu Tanninen  
**Kurssi:** Git-versionhallinta  
**Toteutuksen tunniste:** SOF013AS2A-3003  
**Oppilaitos:** Haaga-Helian Ammattikorkeakoulu  

## Kuvaus

Tämä repositorio sisältää Git-versionhallinta-kurssin kolme oppimispäiväkirjaa.

Ensimmäisessä ja toisessa oppimispäiväkirjassa käsittelen **Paikallinen Git**- ja **Hajautettu Git** -osioiden harjoituksia. Pohdin tehtävissä helppoja ja vaikeita asioita, oppimistani tukeneita tekijöitä, tehtävissä kohtaamieni esteiden ratkaisemista sekä osioissa käyttämiäni Git-komentoja.

Kolmannessa oppimispäiväkirjassa käsittelen **Git projektissa** -osiota. Pohdin versionhallinnan hyötyjä yksin ja usean kehittäjän projekteissa sekä sitä, miten versionhallinta kannattaisi järjestää pienessä ohjelmistoprojektitiimissä. Lisäksi arvioin opintojakson sisältöä, materiaalia, työmäärää ja hyödyllisyyttä sekä esitän omia kehitysehdotuksiani.
